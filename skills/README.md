# Half-Shell Skills

Agent-portable protocols used by Half-Shell.

Skills are versioned independently from the GitHub App runtime so the same review behavior can be used by Claude, Codex/AGENTS.md-compatible agents, generic LLM runtimes, and the Half-Shell service itself.

## Available skills

- [`half-shell-review`](./half-shell-review/) — The Dojo adversarial pull-request review protocol.
